# Төгрөг — Personal Finance PWA (project memory)

Mongolian-language, offline-first personal finance PWA. No framework, no bundler, no
dependencies at runtime: plain HTML/CSS/JS in one file, plus a small PHP + MySQL sync API.
Data lives in the browser's IndexedDB; signed-in users sync it, end-to-end encrypted, across devices.
About 70% of users are on iOS: every offline/sync decision has to work on iOS Safari and home-screen PWAs.

Current version: **1.3** (`sw.js` cache `togrog-v1.3.0-<commit>`). Author: Battseren.

---

## 1. Files

| File | Role |
|---|---|
| `src.html` | **Source of truth.** Page body + `<style>` + `<script>`, no `<html>/<head>/<body>` tags. Edit this one. |
| `index.html` | **Generated** by `tools/build.py` (adds `<head>`, PWA meta, manifest/icon links). Do not edit by hand. |
| `tools/build.py` | Builds `index.html`, `manifest.webmanifest`, and all icons from `src.html`, and stamps `sw.js` `BUILD`. Needs Pillow. |
| `sw.js` | Service worker: app shell cache-first, navigation network-first (falls back to cache after 4s), Google Fonts stale-while-revalidate, `/api/` never cached. `BUILD` = hash of the built app, written by `build.py`. |
| `api/index.php` | Sync API (register / login / logout / sync). Creates its tables on first register/login. |
| `api/config.php` | DB credentials. **Not in git, not deployed**; created by hand on each server from `api/config.sample.php`. |
| `api/.htaccess` | Only `index.php` is reachable. |
| `.htaccess` | Hides `.git`, `.github`, `tools/`, `src.html`, `*.md` (the whole repo is deployed); `no-cache` on `index.html`, `sw.js`, manifest. |
| `manifest.webmanifest` | Generated. Includes `share_target` (GET, `title`/`text` params) for Android "Share → Төгрөг". |
| `icon-192.png`, `icon-512.png`, `icon-maskable.png`, `apple-touch-icon.png` | Generated (₮ glyph on `#0F6B57`). |
| `README.md` | Short user-facing run/deploy notes (Mongolian). |

The `src.html` / `index.html` split exists because `src.html` is also published as a Claude
artifact (the artifact host adds its own skeleton). Production uses `index.html`.

## 2. Workflow

```bash
# edit src.html, then:
python3 tools/build.py          # regenerates index.html, manifest, icons
# local: WAMP serves http://localhost/togrog/ (PHP + MySQL, api/config.php points at db `togrog`)
```

Quick syntax check:
```bash
node -e "const h=require('fs').readFileSync('index.html','utf8');new Function(h.split('<script>')[1].split('</script>')[0]);console.log('js ok')"
```

Deploy: **Hostinger hPanel → Git** deploys `main` straight into `public_html` (no build step on the server).
So `index.html`, the icons, and the stamped `sw.js` must be committed: always run `tools/build.py` before
committing. `api/config.php` is created by hand on the server and is gitignored, so deploys don't touch it.
Server needs PHP 8.1+, MySQL, SSL. All paths are relative, so a subfolder works.

Release checklist:
1. Edit `src.html`
2. Bump the version label in `vPrefs()` ("Төгрөг · хувилбар X.Y") and `VERSION` in `sw.js` for a feature release
3. `python3 tools/build.py` (also gives `sw.js` a new `BUILD`, so phones drop the old cache), syntax check
4. Commit everything, including `index.html` and `sw.js`, and push to `main`
5. Test on an iPhone (installed PWA) and Android

## 3. Data model

Local database: IndexedDB `togrog`, object store `kv` (falls back to `localStorage` keys `togrog.<key>`
if IDB fails; the flag `togrog.useLS` makes that sticky). Keys:
- `auth` → `{token, user:{id,name}, key, expired?}` or null (`key` = base64 AES key, see Sync)
- `data:<scope>` → `S`; `sync:<scope>` → `SY`. `scope` = `local` when signed out, `u<userId>` when signed in,
  so several people can share one phone.
- v1.2 stored `S` in `localStorage['togrog.finance.v1']`; it is moved into `data:local` on first load and removed.

One JSON object `S`:

```js
S = {
  v: 1,
  sample: false,            // true while demo data is loaded (shows the banner on Home)
  loanCats: 1,              // loan categories were seeded once (so deleting them sticks)
  accounts:   [{ id, name, type: 'cash'|'bank'|'card'|'saving', initial, bank? }],  // bank = BANK_LIST id
  categories: [{ id, name, kind: 'expense'|'income', color, loan?: 'out'|'in' }],
  tx: [{
    id, type: 'expense'|'income'|'transfer',
    amount,                 // integer MNT, always positive; sign comes from type
    date: 'YYYY-MM-DD',
    catId,                  // null for transfers
    accId, toAccId,         // toAccId only for transfers
    note,
    ts,                     // created/edited timestamp, tie-breaker for sorting
    recId?,                 // set if generated by a recurring rule
    src?,                   // 'sms' if imported from SMS
    who?                    // person, only for loan categories
  }],
  budgets: { [catId]: monthlyLimit },     // monthly, repeats every month
  recurring: [{
    id, type, amount, catId, accId, toAccId, note,
    day,                    // 1–31; clamped to month length
    start: 'YYYY-MM',       // first month still to consider
    done: ['YYYY-MM', ...]  // months already generated (deleting a tx won't regenerate it)
  }],
  goals: [{
    id, name, target, deadline: 'YYYY-MM' | '', color,
    moves: [{ date, amount }]   // +deposit / −withdrawal; progress only, NOT linked to accounts
  }],
  smsSeen: [hash, ...]      // hashes of imported SMS texts, max 500, for duplicate detection
}
```

Rules:
- **Balances are never stored.** `balance(a)` = `a.initial` + income − expense ± transfers.
- Transfers don't count as income or expense in totals, budgets, or reports.
- Default category ids: expenses `e0`–`e14`, income `i0`–`i4`. `CAT_HINTS` (SMS) refers to these ids:
  `e0` Хоол хүнс, `e1` Кафе, `e2` Тээвэр, `e3` Шатахуун, `e4` Орон сууц, `e5` Ашиглалт,
  `e6` Утас/интернет, `e7` Эрүүл мэнд, `e8` Хувцас, `e11` Зугаа цэнгэл, `e12` Спорт, `i0` Цалин.
  Loan categories (v1.3): `e15` Зээл өгсөн (`loan:'out'`), `i5` Зээл буцаан авсан (`loan:'in'`), added by `migrate()` once.
  They count as normal expense/income in totals and reports.
- Default accounts: `a1` Бэлэн мөнгө, `a2` Харилцах данс, `a3` Хадгаламж.
- Recurring-generated tx ids are `<ruleId>_<YYYY-MM>`, so two offline devices create the same record, not a duplicate.
- **Schema changes:** add defaults in `migrate()` (runs on load, import, sign-in). Never rename
  storage keys without a migration path, or users lose data. A new top-level field of `S` must also be
  added to `recs()` or it won't sync.

### Sync (v1.3)

- Every record is a key `coll/id`: `acc/` `cat/` `tx/` `rec/` `goal/` (array items by id), `bud/<catId>` → `{v}`,
  `meta/prefs` → `{sample, smsSeen, loanCats}`. `recs(S)` builds that map.
- `SY = {base:{key:hash}, outbox:{key:editTimeMs}, cursor, last, hold?}`. `save()` → `track()` diffs `recs(S)`
  against `base` and marks changed/deleted keys in `outbox`. Mutation sites don't need to know about sync:
  keep using `save(); render();`.
- `sync()` pushes up to 300 outbox keys (current value, encrypted) and pulls records with `rev > cursor`
  (500 per page). Conflicts per record: newest `u` (client edit time, clamped to server time + 60s) wins;
  the server returns its copy when it rejects a push. Deletes are tombstones (`del=1`).
- `hold` = this scope has no local copy yet: download first, track afterwards (prevents pushing an empty
  state over the account).
- First sign-in on a device downloads the account. If the account is empty, it is seeded with this
  device's guest data (unless it's the demo data), and `data:local` is cleared.
- Sign-out deletes this account's local copy (asks first if the outbox isn't empty).
- **Triggers** (iOS has no Background Sync): on load, on `visibilitychange` → visible, `online`, every 60s
  while visible, 1.5s after a change, and on hide/`pagehide` as a `keepalive` fetch (≤40 records).
  `navigator.onLine` is not trusted; requests just time out after 20s.
- On load and on return to the app, `applyRecurring` runs **after** the first sync attempt.
- Other tabs get a `BroadcastChannel('togrog')` message and reload `S` from IDB (`'auth'` → full reload).
- Header cloud icon `#sync` shows state: `ok` / `wait` / `busy` / `off` / `auth` (token revoked → "Дахин нэвтрэх",
  local changes are kept and pushed after re-login).

### Accounts and encryption

- Identity is a self-chosen username (3–32 chars, letters/digits/`._-`, lowercased + NFC) and a password.
  No email/phone: the server doesn't need to know who the user is.
- `PBKDF2-SHA256(password, 'togrog/v1/'+username, 310k) → 512 bits`. First 256 bits (base64) = login secret
  sent as `auth` (server stores `password_hash` of it). Last 256 bits = AES-GCM key, stays on the device.
- Each record's `d` is `base64(iv ‖ AES-GCM(JSON, aad=key))`. The server sees only keys, timestamps, and sizes.
- Forgotten password = server data can't be recovered (by design). There is no password change yet
  (it would need re-encrypting every record).
- Needs a secure context (`crypto.subtle`): HTTPS or `localhost`.

### Server (`api/index.php`)

`POST ?a=register|login|logout|sync`, JSON body, `X-Token` header (not `Authorization`: some shared hosts
strip it). Tables: `users(id, name, auth, rev)`, `tokens(hash=sha256(token), user_id, last_used)` (unused
180 days → deleted), `records(user_id, k, d, u, del, rev)`, `attempts` (rate limits: 10 failed logins /
15 min, 5 registrations / hour per IP). `users.rev` is a per-user counter locked with `FOR UPDATE`.

## 4. Code map (`src.html` `<script>`, one IIFE)

**Helpers:** `esc` (HTML escape, use for ALL user text), `uid`, `grp` (1,234,000),
`fmt` (−1,234₮), `compact` (2.8 сая / 450 мян), `iso`, `today`, `ym`, `shiftM(m,k)`,
`mLabel`, `dim` (days in month), `dayLabel`, `parseAmt`, `monthsBetween`.

**Data:** `defaults()`, `sample()` (seeded PRNG, 6 months of demo data plus recurring rules and goals),
`store` (IDB get/set/del), `migrate()`, `save()`, `persist()`, `applyRecurring(st)` → number generated, `balance`, `monthTx`,
`totals(m)`, `spent(m)` (by category), `sorted`, `goalSaved`, `upcoming()`,
`usage(type)` (quick-add combos, category frequency, note suggestions; last 90 days).

**Views** (return HTML strings, `render()` puts them in `#view`):
`vHome`, `vTxs`, `vBudget`, `vReport`, `vPrefs`. Row builders: `txRow`, `budRow`, `goalRow`.

**Routing:** hash-based: `#home #txs #budget #report #prefs`. `route()` on `hashchange`.
State: `tab`, `cur` (selected month `YYYY-MM`), `filter`, `q`, `draft`.

**Banks / loans / notifications:** `BANK_LIST` (id, name, short, key, color, SMS regex), `bankOf`, `bankAccName`,
`loanCat`, `loans()` (per person: out, back, left, since = oldest unpaid loan, FIFO), `loanOpen`, `loanTx`,
`notices()` (computed every render), `bellUI` (header count + `setAppBadge`), `notifSheet`. Seen notice ids:
`localStorage['togrog.seenN']` (per device, not synced).

**Sync:** `recs`, `track`, `sync(opt)`, `syncRun`, `applyRemote`, `api`, `seal`/`open_` (AES-GCM),
`deriveKeys`, `signIn(mode,name,pass)`, `signOut`, `syncUI`, `syncText`, `catchUp` (recurring after sync).

**Bottom sheets** (modals): `openSheet(html)` / `closeSheet()`, `ask(msg, okLabel, fn)`
(in-page confirm; native `confirm()` isn't used). Sheets: `txSheet`, `accSheet`, `catSheet`,
`budSheet`, `recSheet`, `goalSheet`, `goalOpen`, `smsSheet`, `smsParse`, `authSheet(mode)`.

**Events:** one delegated `click` listener switching on `data-act` (plus `data-id`, `data-v`);
one `submit` listener keyed by form id (`tx-form`, `acc-form`, `cat-form`, `bud-form`,
`rec-form`, `goal-form`, `move-form`, `sms-form`, `smsok-form`, `auth-form`). New actions go into both.
Amount inputs (`#f-amount`, `#f-init`) auto-format with thousands separators on `input`.

**Other triggers:** see Sync triggers above. `?text=` / `?title=` query (share target) opens the SMS sheet.
The script is one `async` IIFE: it awaits IndexedDB before the first render.

## 5. Features

- **Accounts, transactions, transfers.** Month switcher in the header. Search and type filter.
- **Budgets:** per expense category, monthly. Bar turns warn at ≥80%, danger at >100%.
  Home shows the 3 most-used budgets and projects month-end spending at the current pace.
- **Recurring (v1.1):** "Сар бүр давтах" checkbox on a new transaction creates a rule.
  A past start date back-fills missing months. Edit or stop under Тохиргоо → Давтагдах гүйлгээ.
  Stopping keeps the transactions already generated.
- **Quick add (v1.1):** combos used ≥2 times (same category + note + account, non-recurring)
  in the last 90 days appear as buttons. Categories are sorted by frequency. Notes autocomplete via `<datalist>`.
- **Savings goals (v1.1):** target, optional deadline, required monthly amount =
  remaining ÷ months left (rounded up to 1,000₮). Deposits and withdrawals only track progress.
- **Bank SMS import (v1.2):** paste one or more SMS (separated by a blank line), or use
  Android Share. `smsOne()` extracts:
  - amount: needs MNT/₮/төг or a keyword/sign; skips amounts after "үлдэгдэл/uldegdel/balance/bal"
  - type: from +/− signs and orlogo/zarlaga, credit/debit, POS words (Cyrillic and Latin)
  - date: `YYYY/MM/DD`, `DD/MM/YYYY`, `YY.MM.DD`; future or invalid dates fall back to today
  - note: "Гүйлгээний утга / utga / тайлбар", otherwise the POS merchant
  - account: bank name (`BANKS`) matched against account names, otherwise the first bank account
  - category: past transaction with a similar note, then `CAT_HINTS`, then "Бусад"
  - duplicates: SMS hash in `smsSeen`, or the same type + amount + date already exists
  - The user reviews and edits every row before saving.
  - **Not yet tested against real bank SMS formats.** Tune `smsOne` once real samples arrive.
- **Reports:** expense donut by category, 6-month income vs expense bar chart (SVG, hand-drawn),
  savings rate, 6-month average.
- **Data:** JSON backup/restore, CSV export (UTF-8 BOM, Excel-friendly), copy JSON,
  load sample, delete all.
- **PWA:** installable, offline, `beforeinstallprompt` button on Android, instructions for iOS.
- **Accounts + sync (v1.3):** Тохиргоо → Бүртгэл, синк. Works signed out exactly as before.
- **Banks (v1.3):** account sheet has a Банк picker (13 Mongolian banks); picking one fills the name
  ("Хаан банк", "Голомт карт", "Хас хадгаламж"). SMS import matches `account.bank` first, then the name.
- **Loans (v1.3):** choosing a loan category shows "Хэнд зээлдүүлсэн / Хэнээс буцаан авсан" (required,
  autocompletes known people). Home shows "Зээлдүүлсэн" (outstanding per person); tapping one opens its
  history with "Буцаан авсан" (prefilled with the remaining amount) and "Дахин зээлдүүлэх".
- **Notifications (v1.3):** bell in the header with an unread count, also on the app icon (Badging API).
  Notices: budget ≥80% / over, recurring due within 3 days, loan unpaid ≥30 days, goal deadline this or
  next month, sign-in expired, changes unsynced for a day, signed-out user with ≥20 tx. In-app only:
  nothing is shown while the app is closed.
- **Demo data:** last 3 months; cash, current accounts at Хаан and Голомт, cards at ХХБ and Голомт,
  savings at Хаан, Хас, Төрийн (with monthly interest), card repayments, savings transfers, loans to 4 people.

### iOS notes
- Safari (not installed) can evict all site storage after ~7 days without use; installed PWAs are exempt.
  The app calls `navigator.storage.persist()` and tells iOS users to install.
- The installed PWA has storage separate from Safari: users sign in again inside the app.
- No Background Sync / periodic sync: see the trigger list. The app can be frozen right after
  `visibilitychange` → hidden, hence the keepalive push.
- IDB connections can drop while backgrounded: `store` reopens once, then falls back to localStorage.

## 6. Design system

Layout: single column, max 560px, sticky month header, fixed 5-tab bottom nav,
FAB (+) for a new transaction, bottom sheets for all forms.

Tokens (`:root`, with dark-mode overrides under `prefers-color-scheme` and `[data-theme]`):
`--bg --surface --surface-2 --fg --muted --line --accent --accent-fg --accent-soft
--income --expense --warn --danger`. Accent is deep green `#0F6B57` (dark `#52C4A2`).
Fonts: **Roboto** (display: titles, brand, big numbers, section labels) + **Roboto Condensed** (all other text,
including textareas). Use only these two.
Numbers use `.num` (tabular-nums). Safe-area insets are handled on the header, nav, FAB, and sheets.
Always use tokens, never literal colors (except category/goal palette colors).

## 7. Conventions

- UI copy is **Mongolian (Cyrillic)**. Currency is formatted as `1,234,000₮`. No decimals; MNT is an integer.
- Escape every user string with `esc()` before putting it into HTML templates.
- Validation errors go in `#f-err` inside the sheet. Success feedback goes through `toast()`.
- After any mutation: `save(); render();` (and `closeSheet()` if a sheet is open).
- Destructive actions go through `ask()`.
- Wrap every `localStorage` access in try/catch (private mode can throw).

## 8. Known limits / backlog

- Signed-out users: data is per browser and per device. Signed-in users: server copy is encrypted; a forgotten password can't be recovered.
- A web app can't read the SMS inbox. Import is paste or Share only (Share works on Android with the app installed).
- No PIN/biometric lock, no multi-currency, no loans/debts tracking yet.
- Backlog, in priority order:
  1. Tune SMS parser with real Хаан / Голомт / ХХБ / ХАС samples
  2. ~~Multi-device sync~~ (done in 1.3). Next: password change (re-encrypt), delete account, recovery key
  3. PIN / WebAuthn lock (local unlock; the stored AES key makes this the next privacy step)
  4. Push notifications while the app is closed: Web Push (iOS 16.4+, installed PWA only) needs VAPID keys,
     a server cron, and stored subscriptions. The server can't read the data (E2E), so the device must
     upload its own reminder schedule with encrypted texts and the service worker decrypts them with the key in IDB.
  5. Backup reminder (no backup in 7 days)
  6. Debts I owe (borrowed money), multi-currency (USD/KRW/CNY)
  7. Daily spending heatmap, month-over-month category comparison
